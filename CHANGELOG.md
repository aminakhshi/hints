# Changelog

All notable changes to `HiNTS` are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.3] - 2026-08-16

### Added

- Optional PyTorch backend (`backend='torch'`, `device=...`, `dtype=...`) for
  accumulating the moments of large datasets on a GPU. It is an optional extra:
  the package runs on NumPy by default and falls back to it, with a warning, if
  PyTorch or the requested device is unavailable.
- Alternative linear solvers through `solver='lstsq'` or `solver='pinv'`, and
  the condition number of the moment matrix is now recorded in
  `condition_number` and reported when it becomes large.
- Loading time series from `.npz` and `.mat` files, and accepting
  `pandas.DataFrame`, `Series` and nested sequences as input.
- A regression test suite under `tests/`.

### Fixed

- Loading a time series from a file raised `TypeError`, because `_load_data()`
  was defined without the parameter it was called with. This affected every
  file based entry point, including the example in the README. Reported in pull
  request [#1](https://github.com/aminakhshi/hints/pull/1).
- A sample count that divided evenly by the window size caused the trailing
  segment to be accumulated twice, doubling the work per call.
- Passing neither `filepath` nor `ts_array` raised an unclear `AttributeError`.
- Input validation used bare `assert` statements, which are removed when Python
  runs with `-O`. Invalid arguments now raise `ValueError` or `TypeError`.
- A docstring emitted a `SyntaxWarning` on import.
- The published API documentation was empty: Read the Docs never installed the
  package, so `autodoc` could not import it, and the resulting warning did not
  fail the build. The notebook example also could not be rendered because the
  `pandoc` binary was missing from the build image.
- The documentation reported a version that had drifted from the package.

### Changed

- Coefficient tables now use consistent, one-based labels. Drift columns are
  `F_x1 ... F_xN` and diffusion columns `D_x1x1`, `D_x1x2`, ... , replacing the
  previous unnamed drift columns and zero-based diffusion labels such as `01`.
- `jitcsde`, `sympy`, `tqdm` and `ipykernel` are no longer mandatory
  dependencies. None of them is imported by the package, and `jitcsde` is
  compiled, so a machine without a build toolchain could not install `HiNTS` at
  all. They are available as the `examples` extra for the notebooks.
- The distribution no longer installs a top level package named `examples`,
  which previously claimed that name in every environment.
- `scikit-image` is no longer required; the single function used from it was
  replaced with an equivalent reshape.
- Documentation builds on Python 3.11 and the usage page now covers the API in
  addition to the autogenerated reference.

### Note on results

This release does not change the numerical convention of the estimator or its
behaviour at finite sampling interval. Diffusion coefficients continue to follow
`D^(2)_ij = <dx_i dx_j> / dt`, without a factor of one half. Coefficient values
are unchanged; only their column labels differ.

## [0.1.2] - 2024-03-28

### Fixed

- Minor fixes to the diffusion mode estimation.

## [0.1.1] - 2024-03

### Changed

- README updates and version history automation.

## [0.1.0] - 2024-03

### Added

- Initial beta release: estimation of drift and diffusion Kramers-Moyal
  coefficients from N-dimensional time series, following Tabar et al.,
  *Phys. Rev. X* **14**, 011050 (2024).
